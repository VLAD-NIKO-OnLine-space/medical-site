# scr-system

Сайт на PHP: шапка, подвал и `<head>` лежат в одном месте, страницы содержат только свой контент. Сайт работает как живой PHP-сайт или собирается в статический HTML.

## Структура

| Что | Где |
|---|---|
| Домен и язык | `config.php` |
| Тексты, ссылки, меню, кнопки, карточки главной | редактируются в админке `/admin/`, хранятся в `data/site.sqlite` |
| Что редактируется в админке (схема полей и значения по умолчанию) | `content.php` |
| Админка | `admin/`, стили и скрипт — `public/assets/admin/` |
| Создать администратора / сменить пароль | `php admin-user.php <логин> [пароль]` |
| `<head>`: мета, canonical, og-теги, CSS | `templates/head.php` |
| Шапка | `templates/header.php` |
| Секции главной | `templates/hero.php`, `templates/questions.php` |
| Подвал | `templates/footer.php` |
| Каркас страницы | `templates/layout.php` |
| Страницы | `pages/*.php` |
| Страница 404 | `pages/404.php` |
| CSS, JS, картинки | `public/assets/` |
| Фон первого экрана | `public/assets/img/hero-*` (AVIF/WebP/JPEG, десктоп и мобильная обрезка), исходник — `my-files/` |
| Обложка видео на первом экране | `public/assets/img/video-cover-*` |
| Иконки (Lucide) | `icons.php`, вывод — `<?= icon('calendar') ?>` |
| Анимация иконок при наведении (Morphicons) | `public/assets/js/icons.js`, `public/assets/js/vendor/morphicons/` |
| Маршрутизация (живой режим) | `public/index.php`, `public/.htaccess` |
| Сборка в статику | `build.php` |

## Добавить страницу

Создать файл в `pages/`. Адрес берётся из имени файла:

| Файл | Адрес |
|---|---|
| `pages/index.php` | `/` |
| `pages/kontakty.php` | `/kontakty/` |
| `pages/blog/index.php` | `/blog/` |
| `pages/blog/post.php` | `/blog/post/` |

Содержимое файла:

```php
<?php
$page['title'] = 'Контакты — Название сайта';
$page['description'] = 'Как с нами связаться.';
?>
<div class="container">
<h1>Контакты</h1>
<p>Текст страницы.</p>
</div>
```

Необязательно: `$page['robots'] = 'noindex, follow';` — закрыть страницу от индексации.

Страница сразу открывается по своему адресу и попадает в `sitemap.xml`. В меню она попадает, только если добавить её в `nav` в `config.php`.

## Где работает сайт

Проект лежит в **`/var/www/scr-system`** (`/root/scr-system` — ссылка на эту папку). Сайт постоянно работает через **nginx + PHP-FPM** и открыт по адресу **http://164.90.165.153** (админка — **http://164.90.165.153/admin/**). Туннель и ручной запуск сервера не нужны. Правки в `pages/`, `templates/`, `config.php`, `content.php` и `public/assets/` видны сразу после обновления страницы.

| Что | Где |
|---|---|
| Конфиг nginx | `/etc/nginx/sites-available/scr-system` (корень — `public/`, всё, кроме файлов, идёт в `public/index.php`) |
| Логи nginx | `/var/log/nginx/access.log`, `/var/log/nginx/error.log` |
| PHP | `php8.3-fpm`, работает от пользователя `www-data` |
| Права | `data/` принадлежит `www-data` — PHP пишет туда базу |

Управление (на сервере):

```bash
systemctl status nginx php8.3-fpm               # состояние
systemctl restart php8.3-fpm                     # после установки PHP-модулей
nginx -t && systemctl reload nginx               # после правки конфига nginx
systemctl stop nginx                             # выключить сайт
systemctl start nginx                            # включить сайт
```

Оба сервиса в автозагрузке — после перезагрузки сервера сайт поднимется сам.

### Запасной вариант: встроенный сервер PHP + SSH-туннель

Если nginx выключен, сайт можно посмотреть встроенным сервером PHP. На сервере:

```bash
cd /var/www/scr-system && setsid nohup php -S 127.0.0.1:8000 -t public public/index.php > data/dev-server.log 2>&1 &
pkill -f "php -S 127.0.0.1:8000"     # остановить
```

На своём устройстве — туннель (флаг **`-N` обязателен**: без него SSH заходит на сервер и `.bashrc` подключает к tmux-сессии `main`, где работает Claude, — всё будет дублироваться):

```bash
ssh -N -L 8000:127.0.0.1:8000 root@164.90.165.153
```

и открыть **http://localhost:8000**. Закрыть туннель — `Ctrl+C` в его окне.

## Админка

Адрес: **/admin/** (сейчас — http://164.90.165.153/admin/). Закрыта от поисковиков (`robots.txt`, `noindex`).

Редактируется всё на главной, в шапке и подвале: тексты, заголовки, ссылки, пункты меню, кнопки, карточки и их иконки. Пункты меню, карточки и ссылки подвала можно добавлять, удалять и менять местами. После «Сохранить» изменения сразу видны на сайте.

Контент хранится в SQLite: `data/site.sqlite` (создаётся сам при первом запросе). Пока поле ни разу не сохраняли, на сайте значение по умолчанию из `content.php`.

**Администратор:**

```bash
php admin-user.php admin            # создать admin со случайным паролем (пароль выведется)
php admin-user.php admin 'НовыйПароль'   # задать пароль (не короче 8 символов)
```

Защита: вход по логину и паролю (пароли хранятся хэшами), после 5 неверных попыток вход с этого IP блокируется на 15 минут, все формы защищены CSRF-токеном, ссылки принимаются только вида `/…`, `#…`, `https://…`, `mailto:`, `tel:`, любой HTML в текстах выводится как текст.

**Сделать новое поле редактируемым:** добавить его в `content.php` (тип `text`, `textarea`, `url`, `icon` или `list`) и вывести в шаблоне через `content('блок')['поле']` — форма в админке появится сама.

## Сборка в статику

```bash
cd /var/www/scr-system
php build.php
```

Результат — папка `dist/`:

- каждая страница — `путь/index.html`;
- `404.html` и `.htaccess` с `ErrorDocument 404 /404.html`;
- `sitemap.xml` и `robots.txt` — генерируются из списка страниц;
- содержимое `public/assets/`.

Папка `dist/` пересоздаётся с нуля при каждой сборке — руками в ней ничего не править.

## Деплой

**Живой PHP (основной вариант, с админкой):** залить папку целиком, корнем сайта (DocumentRoot) указать `public/`. Нужны PHP 8.1+, расширение `pdo_sqlite` и `mod_rewrite` для `.htaccess`. Папка `data/` должна быть доступна PHP на запись. Остальные папки (`admin/`, `data/`, `pages/`, `templates/`, `config.php`, `content.php`) остаются вне корня и снаружи недоступны. После заливки создать администратора: `php admin-user.php admin`.

`data/` не хранится в git — это живые данные сайта. При обновлении кода на хостинге её не перезаписывать; бэкап контента — скопировать `data/site.sqlite`.

**Статика (без админки):** залить содержимое `dist/` в корень сайта на Apache. В статику попадает контент на момент сборки.

## Перед запуском сайта

- В `config.php` заменить `https://example.com` на реальный домен — от него строятся canonical, `og:url`, `sitemap.xml` и `robots.txt`.
- Создать администратора и в админке заменить название сайта и тексты.
- Поменять язык (`lang`) в `config.php`, если нужно.
