# scr-system

Сайт на PHP: шапка, подвал и `<head>` лежат в одном месте, страницы содержат только свой контент. Сайт работает как живой PHP-сайт или собирается в статический HTML.

## Структура

| Что | Где |
|---|---|
| Домен и язык | `config.php` |
| Тексты, ссылки, меню, кнопки, карточки главной | редактируются в админке `/admin/`, хранятся в `data/site.sqlite` |
| Что редактируется в админке (схема полей и значения по умолчанию) | `content.php` |
| Админка | `admin/`, стили и скрипт — `public/assets/admin/` |
| Создать администратора / сменить пароль | `php admin-user.php <логин> [пароль]` |
| `<head>`: мета, canonical, og-теги, CSS, предзагрузка шрифта и модулей | `templates/head.php` |
| Шрифты Inter и Unbounded (свой сервер, не Google Fonts) | `public/assets/fonts/`, подключение — в начале `style.css` |
| Слайдер отзывов (Swiper) | `public/assets/js/reviews.js`, `public/assets/js/vendor/swiper/` |
| Копия конфига nginx (сжатие, кэш, заголовки) | `server/nginx/` |
| Шапка | `templates/header.php` |
| Секции главной | `templates/hero.php`, `about.php` (о видеогиде), `author.php` (об авторе), `program.php`, `reviews.php`, `access.php`, `faq.php` |
| Подвал | `templates/footer.php` |
| Каркас страницы | `templates/layout.php` |
| Страницы | `pages/*.php` |
| Страница 404 | `pages/404.php` |
| CSS, JS, картинки | `public/assets/` |
| Картинки (фон первого экрана, обложка видео, фото врача, фон «Программы») | меняются в админке; загруженные — `public/uploads/`, исходные — `public/assets/img/`; вывод — `picture()` в `lib.php` |
| Загрузка и нарезка картинок | `admin/images.php` (Imagick) |
| Иконки сайта (фавикон, Apple, Android) | `public/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`; манифест `/site.webmanifest` генерируется в `lib.php` (`manifest()`), название — из админки |
| Иконки (Lucide) | `icons.php`, вывод — `<?= icon('calendar') ?>`; какие иконки где — прямо в шаблонах, в админке не меняются |
| Анимация иконок при наведении (Morphicons) | `public/assets/js/icons.js`, `public/assets/js/vendor/morphicons/` |
| Маршрутизация (живой режим) | `public/index.php`, `public/.htaccess` |
| Сборка в статику | `build.php` |

## Добавить страницу

Создать файл в `pages/`. Адрес берётся из имени файла:

| Файл | Адрес |
|---|---|
| `pages/index.php` | `/` |
| `pages/kontakty.php` | `/kontakty/` |
| `pages/blog/index.php` | `/blog/` |
| `pages/blog/post.php` | `/blog/post/` |

Содержимое файла:

```php
<?php
$page['title'] = 'Контакты — Название сайта';
$page['description'] = 'Как с нами связаться.';
?>
<div class="container">
<h1>Контакты</h1>
<p>Текст страницы.</p>
</div>
```

Необязательно: `$page['robots'] = 'noindex, follow';` — закрыть страницу от индексации.

Страница сразу открывается по своему адресу и попадает в `sitemap.xml`. В меню она попадает, только если добавить её в `nav` в `config.php`.

## Где работает сайт

Проект лежит в **`/var/www/scr-system`** (`/root/scr-system` — ссылка на эту папку). Сайт постоянно работает через **nginx + PHP-FPM** и открыт по адресу **http://164.90.165.153** (админка — **http://164.90.165.153/admin/**). Туннель и ручной запуск сервера не нужны. Правки в `pages/`, `templates/`, `config.php`, `content.php` и `public/assets/` видны сразу после обновления страницы.

| Что | Где |
|---|---|
| Конфиг nginx | `/etc/nginx/sites-available/scr-system` (корень — `public/`, всё, кроме файлов, идёт в `public/index.php`) |
| Логи nginx | `/var/log/nginx/access.log`, `/var/log/nginx/error.log` |
| PHP | `php8.3-fpm`, работает от пользователя `www-data` |
| Права | `data/` принадлежит `www-data` — PHP пишет туда базу |

Управление (на сервере):

```bash
systemctl status nginx php8.3-fpm               # состояние
systemctl restart php8.3-fpm                     # после установки PHP-модулей
nginx -t && systemctl reload nginx               # после правки конфига nginx
systemctl stop nginx                             # выключить сайт
systemctl start nginx                            # включить сайт
```

Оба сервиса в автозагрузке — после перезагрузки сервера сайт поднимется сам.

### Запасной вариант: встроенный сервер PHP + SSH-туннель

Если nginx выключен, сайт можно посмотреть встроенным сервером PHP. На сервере:

```bash
cd /var/www/scr-system && setsid nohup php -S 127.0.0.1:8000 -t public public/index.php > data/dev-server.log 2>&1 &
pkill -f "php -S 127.0.0.1:8000"     # остановить
```

На своём устройстве — туннель (флаг **`-N` обязателен**: без него SSH заходит на сервер и `.bashrc` подключает к tmux-сессии `main`, где работает Claude, — всё будет дублироваться):

```bash
ssh -N -L 8000:127.0.0.1:8000 root@164.90.165.153
```

и открыть **http://localhost:8000**. Закрыть туннель — `Ctrl+C` в его окне.

## Скорость загрузки

- **Шрифт** — Inter со своего сервера, вариативный (один файл на все начертания). `inter-core.woff2` (~37 КБ) содержит только символы текстов сайта: русский и латинский алфавит, цифры, знаки препинания, ₽. Он предзагружается в `head.php`. Полные `inter-cyrillic.woff2` и `inter-latin.woff2` браузер скачает, только если в тексте из админки встретится символ не из core (например, «é»). Пересобрать core под новый набор символов можно через `pyftsubset` из fonttools.
- **Акцентная строка заголовка первого экрана** — Unbounded 500, `unbounded-500.woff2` (~18 КБ, только русский и латинский алфавит, цифры и знаки). Тоже предзагружается. Если понадобятся другие символы — пересобрать из исходника Google Fonts: `fonttools varLib.instancer … wght=500`, затем `pyftsubset`.
- **CSS и JS подключаются через `asset('/assets/…')`** — к адресу добавляется `?v=<время изменения файла>`. Такие файлы сервер кэширует в браузере на год: после правки адрес меняется, и браузер сразу берёт новую версию. Картинки, шрифты и модули из `vendor/` без метки кэшируются на 30 дней. Поэтому **заменённую картинку сохранять под новым именем**, иначе посетители до 30 дней будут видеть старую.
- **Свои CSS/JS для секции** шаблон добавляет в `$page['styles']` / `$page['scripts']` (см. `templates/reviews.php`) — они подключаются только на страницах с этой секцией.
- **Swiper** (~40 КБ) скачивается, только когда до отзывов остаётся около экрана прокрутки.
- **Модули Morphicons** предзагружаются все сразу (`modulepreload` в `head.php`), а не цепочкой. Если обновить Morphicons и имена файлов изменятся — поправить список в `head.php`.
- **Картинки** — AVIF/WebP/JPEG нескольких размеров через `<picture>`, у всех заданы `width`/`height`. Картинка первого экрана — `fetchpriority="high"`, ниже первого экрана — `loading="lazy"`.
- **Сервер** (`server/nginx/` — копия рабочего конфига из `/etc/nginx/`): gzip, кэш по правилам выше, заголовки безопасности, версия nginx скрыта. Для Apache те же правила — в `public/.htaccess`, при сборке они попадают в `dist/.htaccess`.

После правки конфига на сервере обновить копию в репозитории:

```bash
cp /etc/nginx/sites-available/scr-system server/nginx/scr-system.conf
cp /etc/nginx/snippets/scr-headers.conf server/nginx/scr-headers.conf
```

## Админка

Адрес: **/admin/** (сейчас — http://164.90.165.153/admin/). Закрыта от поисковиков (`robots.txt`, `noindex`).

Админка разделена на три раздела (вкладки в шапке), каждый сохраняется отдельно и не трогает остальные:

- **Контент сайта** — `/admin/`: общие настройки, шапка, секции главной, подвал;
- **Отзывы** — `/admin/otzyvy/`: очередь модерации, опубликованные отзывы, заголовок секции;
- **Страницы** — `/admin/stranicy/`: внутренние страницы (сейчас «Условия покупки»), у каждой ссылка «Открыть страницу».

Раздел блока задаёт ключ `group` в `content.php` (`content` по умолчанию, `reviews`, `pages`; у страниц ещё `url`). Новая внутренняя страница: шаблон в `pages/`, блок с `'group' => 'pages'` — в разделе «Страницы» она появится сама. Кнопка «Сохранить» — в шапке, неактивна, пока в разделе ничего не изменено.

В админке меняются только тексты (включая ссылки и оценки отзывов) и картинки. Пункты меню, карточки, отзывы и ссылки подвала можно добавлять, удалять и менять местами. После «Сохранить» изменения сразу видны на сайте.

Иконки в админке не меняются — они заданы в шаблонах. В списках с иконками (тезисы «О видеогиде», пункты карточки доступа, карточки контактов) иконка берётся по порядку: первая строка — первая иконка и т. д. Если поменять строки местами, иконки останутся на своих местах; добавленные строки получают галочку (в контактах — «i»).

**Картинки.** «Заменить картинку» → выбрать файл (JPG, PNG, WebP или AVIF, до 20 МБ) → «Сохранить». Сервер сам обрезает её до нужных пропорций по центру (размеры — в подсказке у поля), для фонов отдельно вырезает вертикальную часть для телефона и сохраняет в AVIF, WebP и JPEG нескольких ширин — 3–5 секунд. Новая картинка получает новый адрес, старая удаляется. Фото врача не обрезается и сохраняет прозрачность — лучше PNG с прозрачным фоном. Нужно расширение PHP `imagick` с поддержкой AVIF (на сервере: пакет `php8.3-imagick`), лимит загрузки — `server/php/99-scr-system.ini`.

Контент хранится в SQLite: `data/site.sqlite` (создаётся сам при первом запросе). Пока поле ни разу не сохраняли, на сайте значение по умолчанию из `content.php`.

**Администратор:**

```bash
php admin-user.php admin            # создать admin со случайным паролем (пароль выведется)
php admin-user.php admin 'НовыйПароль'   # задать пароль (не короче 8 символов)
```

Защита: вход по логину и паролю (пароли хранятся хэшами), после 5 неверных попыток вход с этого IP блокируется на 15 минут, все формы защищены CSRF-токеном, ссылки принимаются только вида `/…`, `#…`, `https://…`, `mailto:`, `tel:`, любой HTML в текстах выводится как текст.

**Сделать новое поле редактируемым:** добавить его в `content.php` (тип `text`, `textarea`, `url`, `rating`, `image` или `list`; настройки `image` описаны в начале `content.php`) и вывести в шаблоне через `content('блок')['поле']` — форма в админке появится сама.

## Отзывы с сайта

Кнопка «Оставить отзыв» в секции отзывов открывает окно (`templates/reviews.php`, `public/assets/js/review-form.js`). Кнопка отправки активна, только когда заполнены имя, оценка и текст от 10 символов. Отзыв уходит на `/otzyv/` (`review-queue.php`) и попадает в таблицу `review_queue`. Дата ставится по времени отправки (часовой пояс Europe/Moscow задан в `lib.php`).

Над слайдером — средняя оценка и фильтр «Все / Положительные / С замечаниями» с числом отзывов. Положительные — 4–5 звёзд, «С замечаниями» — 1–3: раздел определяет только оценка автора отзыва, вручную его не задать.

Защита от спама: скрытое поле-ловушка, не больше 3 отзывов в час с одного IP, не больше 300 отзывов в очереди, отправка только со своего сайта (заголовок Origin).

В админке, в разделе «Отзывы», первым стоит блок «Отзывы на модерации» (счётчик новых — на вкладке). «Опубликовать» переносит отзыв в начало списка опубликованных, «Удалить» стирает его. Форма работает только на PHP-сервере: в статической сборке `dist/` отправлять некуда.

## Сборка в статику

```bash
cd /var/www/scr-system
php build.php
```

Результат — папка `dist/`:

- каждая страница — `путь/index.html`;
- `404.html` и `.htaccess` с `ErrorDocument 404 /404.html`;
- `sitemap.xml` и `robots.txt` — генерируются из списка страниц;
- содержимое `public/assets/`.

Папка `dist/` пересоздаётся с нуля при каждой сборке — руками в ней ничего не править.

## Деплой

**Живой PHP (основной вариант, с админкой):** залить папку целиком, корнем сайта (DocumentRoot) указать `public/`. Нужны PHP 8.1+, расширения `pdo_sqlite` и `imagick` (с AVIF), `mod_rewrite` для `.htaccess`. Папки `data/` и `public/uploads/` должны быть доступны PHP на запись; `upload_max_filesize` не меньше 20M. Остальные папки (`admin/`, `data/`, `pages/`, `templates/`, `config.php`, `content.php`) остаются вне корня и снаружи недоступны. После заливки создать администратора: `php admin-user.php admin`.

`data/` не хранится в git — это живые данные сайта. При обновлении кода на хостинге её не перезаписывать; бэкап контента — скопировать `data/site.sqlite`.

**Статика (без админки):** залить содержимое `dist/` в корень сайта на Apache. В статику попадает контент на момент сборки.

## Перед запуском сайта

- Домен `https://bestoncolog.ru` задан в `config.php` — от него строятся canonical, `og:url`, `sitemap.xml` и `robots.txt`. Перед запуском: направить DNS домена на сервер, выпустить сертификат (например, `certbot --nginx -d bestoncolog.ru -d www.bestoncolog.ru`) и включить редирект с http и www на `https://bestoncolog.ru`.
- Создать администратора и в админке заменить название сайта и тексты.
- Поменять язык (`lang`) в `config.php`, если нужно.
- Подключить домен и HTTPS (Let's Encrypt): после этого включить в nginx `http2` и заголовок `Strict-Transport-Security`.
